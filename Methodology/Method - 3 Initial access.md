# 3 Initial access

Back to [[Methodology]]. Comes after [[Method - 2 Enumeration]].

**TL;DR:** turn a finding into a foothold: a shell or valid login. See [[Exploitation]] and [[Web]].

## Checklist

- [ ] Pick the most likely finding from enumeration
- [ ] Get a shell (exploit, upload, command injection) or log in with found creds
- [ ] Set up a listener and catch a reverse shell — see [[Exploitation]]
- [ ] Upgrade to a stable/interactive shell
- [ ] Record the foothold (user, host, shell type) in the State
